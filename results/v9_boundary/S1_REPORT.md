## 0. 结论速览

- **S1 目标达成**：v9 的 DR–FPR 帕累托曲线在 32d 同压缩率下**整体外推于 v8**，且呈 **v8 → A1（数据）→ A2（边界损失）逐级改进**。
- 在攻击 DR≥0.90 处，JBB-Benign FPR：**v8 0.68 → A1 0.61 → 最优 A2 0.56**；在 FPR≤0.2 处可达攻击 DR：**v8 0.556 → A1 0.638 → 最优 A2 0.683**。
- **诚实caveat**：绝对假阳率仍高（DR≥0.95 时最好仍 ~0.65）。JBB-Benign 是对抗式"像有害的正常"，10× 数据 + 边界损失能稳步外推但未彻底解决——暗示部分是 32d 余弦质心几何的固有限制，指向后续 B（决策层）/C（几何）或更高维。

## 2. 方法

- 复用学习型 CS 投影 `LearnedCSProjection(768→32)` + `DualMultiCentroidDetector` + v7 微调编码器。
- **A1**：仅换新数据、原 SupCon 目标，重训 32d（隔离数据效应）。
- **A2**：在 SupCon 上加边界 margin 项 `L = L_supcon + λ·relu(margin + sim(gray_benign,最近harmful) − sim(gray_benign,benign原型))`，网格 λ∈{1.0,2.0} × margin∈{0.3,0.5}（隔离目标效应）。损失含单元测试（`scripts/v9_boundary/test_loss.py`，ALL PASS）。
- 评测：扫阈值 `[-0.5,0.5]` 步长 0.02，攻击集={GCG,PAIR,JailbreakHub,AdvBench,HarmBench}（剔除标注语义不匹配的 ToxicChat/BeaverTails），benign={JBB-Benign, Alpaca 护栏}。

## 4. 消融结论（数据 vs 目标）

- **数据效应（A1）**：单加 gray-benign 数据即把曲线从 v8 外推一截（如 DR≥0.95 时 0.82→0.69）。
- **目标效应（A2）**：边界 margin 在 A1 基础上再外推一小截（如 DR≥0.90 时 0.61→0.56；FPR≤0.2 时 DR 0.638→0.683）。
- 两者**方向一致、可叠加**。最一致的赢家：**a2_l1m5（λ=1.0, margin=0.5）**；低-FPR 部署区最优：a2_l2m3。

## 5. 推荐与局限

- **推荐 v9 配置**：`a2_l1m5`（models/v9_a2_l1.0_m0.5）作为 v9 默认；部署偏好低 FPR 时用 `a2_l2m3`。
- **局限（诚实）**：边界正常假阳率绝对值仍高，32d 余弦质心几何对对抗式边界样本分离能力有限。这是 S1 的明确发现，不是失败——它把"数据能解决多少"和"还差多少"量化清楚了。

## 6. S1 → S2 衔接

- S2（基线 + 消融）对比时，用 **v9（a2_l1m5）** 而非 v8 作为本方法代表（已 Pareto 改进）。
- 后续可选（超出 S1）：B 决策层校准头、C 边界专属质心、更高维或非线性 CS 投影，针对仍然偏高的边界假阳率。
